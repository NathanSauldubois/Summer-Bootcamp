# Portfolio Optimization Project

This folder contains the standalone Session 3 project:

- `portfolio_optimization_project.pdf`: detailed project statement;
- `portfolio_optimization_project.tex`: LaTeX source;
- `portfolio_project_skeleton.py`: guided student template with staged `TODO` blocks.

Recommended setup:

```bash
python -m pip install numpy pandas scipy matplotlib
python portfolio_project_skeleton.py
```

Complete the Python template in project order. The script creates `data/` and
`outputs/` locally when run. Generated train and test data must remain separate,
and test observations must never be used for fitting PCA or selecting
hyperparameters.
